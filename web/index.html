Skypin — Draw an area, list towns, live risk score

Use the toolbar on the map: draw a rectangle or a closed polygon. We query OpenStreetMap (cities/towns/villages), then Open-Meteo, using the same risk formula as the warehouse mart. After each draw, the API can write hourly rows to api.area_selection_hourly so Grafana can chart every place in the polygon, not only CSV cities.

Start API: docker compose up -d api (port 8000). Serve this folder: cd web && python -m http.server 8080. Set API_BASE / GRAFANA_ORIGIN in the script if needed.
